## Свойства объекта

«Свинокол» — меч для ближнего боя.

- Материал — железо (ToolMaterials.IRON).
- Максимальный размер стака — 1.
- Параметры атрибутов атаки, передаваемые в
  SwordItem.createAttributeModifiers: 3 и -2.4f.

Меч доступен во вкладке «Сражение» творческого инвентаря.

## Рецепт и баланс

Рецепт одного меча:
- 2 железных слитка;
- 1 палка;
- 1 сырая свинина.

Железо соответствует материалу клинка, палка — рукояти.
Свинина служит тематическим компонентом рецепта.
Дополнительной способности против свиней пока нет.

## Проверка

Проверены доступность меча в творческом инвентаре
и изготовление на верстаке в режиме выживания.




## ЛР-10. Дополнительное поведение объекта

Для меча «Свинокол» добавлено сообщение
при использовании в основной руке.

### Пользовательский сценарий

1. Исходное состояние: игрок находится в творческом
   режиме или режиме выживания и держит «Свинокол»
   в основной руке.
2. Действие: игрок направляет взгляд в воздух
   и отдельно нажимает правую кнопку мыши.
3. Ожидаемый результат: в чате появляется сообщение
   «Свинокол готов к бою!».

### Реализация

Обработчик UseItemCallback зарегистрирован
в Pig_killer.onInitialize() после регистрации предмета.

Условие stack.isOf(ModItems.PIG_KILLER)
ограничивает поведение нашим предметом.

Дополнительно проверяются основная рука
и отсутствие режима наблюдателя.

Сообщение отправляется только на серверной стороне
при !world.isClient().

Для своего предмета возвращается
TypedActionResult.success(stack).
Для остальных случаев —
TypedActionResult.pass(stack).

Рецепт, текстура и характеристики меча не изменены.

### Проверка

Положительный сценарий:
два отдельных нажатия ПКМ со «Свиноколом»
вызывают по одному сообщению на каждое использование.

Отрицательный сценарий:
нажатие ПКМ с обычным железным мечом
не вызывает сообщение нашего обработчика.
